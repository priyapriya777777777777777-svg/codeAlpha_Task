# Task 3 - Data Visualization

## Objective

The objective of this task is to create meaningful visualizations from the Netflix Movies and TV Shows dataset using Python.

## Dataset

Netflix Movies and TV Shows Dataset

Source: Kaggle

https://www.kaggle.com/datasets/shivamb/netflix-shows

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations Created

- Movies vs TV Shows
- Top 10 Countries Producing Netflix Content
- Netflix Content by Release Year
- Top 10 Content Ratings
- Top 10 Netflix Genres
- Movies vs TV Shows by Release Year
- Ratings Distribution by Content Type

## Key Insights

The visualizations help identify trends and patterns in Netflix content, including content type distribution, popular countries, genres, ratings, and release-year trends.

## Result

The Netflix dataset was transformed into meaningful charts and visual representations to make the data easier to understand and interpret.

- `CodeAlpha_DataVisualization.ipynb` - Visualization code and charts
